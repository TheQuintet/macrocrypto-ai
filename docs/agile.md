# Agile & Sprints

We follow **Agile** methodology with at least **three sprints** over the project. All tasks and user stories must be tracked on an **Agile task board** (e.g., Trello).

**Rule:** If it is not on the board, it is not officially tracked. Keep the board updated during and after each ceremony.

---

## Sprint requirements

- Complete **at least 3 sprints** during the capstone.
- Each sprint should have a clear **goal**, **planned stories/tasks**, and a **review** of what was completed.
- [Product Owner](./team.md) prioritizes; [Scrum Master](./team.md) facilitates.

## User story template

Use this format on the task board:

```
As a [type of user],
I want [goal],
so that [benefit].

Acceptance criteria:
- [ ] ...
- [ ] ...
```

---

## Ceremonies checklist

| Ceremony | Purpose |
|----------|---------|
| **Sprint planning** | Select stories, estimate, assign owners — see [Planning sessions](./meetings/planning.md) |
| **Backlog refinement** | Clarify stories, acceptance criteria, and estimates — see [Refinement sessions](./meetings/refinement.md) |
| **Daily sync / stand-up** | Share progress, blockers, plan for the day |
| **Sprint review** | Demo completed work to the team |
| **Retrospective** | Improve process for the next sprint |
