# Ubiquitous Language — MacroCrypto AI

This document defines the common language used across the MacroCrypto AI platform. All team members, stakeholders, and documentation should use these terms consistently to avoid confusion.

---

## 1. Core Domain Terms

| Term | Definition |
|------|------------|
| **Bitcoin (BTC)** | The cryptocurrency asset that the platform analyzes and predicts |
| **Price** | The current market value of BTC in USD |
| **Prediction** | A forecast of BTC's future price generated by the AI model |
| **Forecast Horizon** | The time period for which a prediction is made (24h or 7d) |
| **Confidence Interval** | The range (upper and lower bounds) where the actual price is expected to fall with a certain probability |
| **Confidence Level** | The probability that the actual price falls within the confidence interval (70%, 85%, or 95%) |

---

## 2. Macroeconomic Terms

| Term | Definition |
|------|------------|
| **Macro Indicator** | An economic metric that describes the broader economic environment |
| **CPI (Consumer Price Index)** | A measure of inflation based on the average change in prices paid by consumers |
| **Inflation** | The rate at which the general level of prices for goods and services is rising |
| **Interest Rate** | The rate at which the central bank lends money to commercial banks |
| **Federal Funds Rate** | The interest rate at which depository institutions lend reserve balances to each other overnight |
| **GDP (Gross Domestic Product)** | The total monetary value of all goods and services produced in a country |
| **Unemployment Rate** | The percentage of the labor force that is jobless and actively seeking employment |
| **M2 Money Supply** | A measure of the money supply that includes cash, checking deposits, and easily convertible near-money |
| **DXY (US Dollar Index)** | A measure of the value of the US dollar relative to a basket of foreign currencies |
| **Treasury Yield** | The return on investment for US government bonds |

---

## 3. Crypto Market Terms

| Term | Definition |
|------|------------|
| **Market Cap** | The total value of all coins in circulation (price × circulating supply) |
| **Volume** | The total value of BTC traded in a given period (24h) |
| **Volatility** | The degree of variation in BTC's price over time (measured by standard deviation) |
| **BTC Dominance** | The percentage of total cryptocurrency market cap represented by BTC |
| **Active Addresses** | The number of unique addresses involved in BTC transactions |
| **On-Chain Data** | Data derived directly from the Bitcoin blockchain |
| **Altcoin** | Any cryptocurrency other than Bitcoin |

---

## 4. Alert Terms

| Term | Definition |
|------|------------|
| **Alert** | A notification triggered when a specific condition is met |
| **Price Alert** | An alert triggered when BTC reaches a specific price level |
| **Prediction Change Alert** | An alert triggered when a prediction changes beyond a threshold |
| **Confidence Change Alert** | An alert triggered when the confidence level changes significantly |
| **Macro Event Alert** | An alert triggered before a major economic event |
| **Alert Type** | The condition that triggers the alert (e.g., price reaches, crosses above, crosses below) |
| **Alert Status** | The current state of an alert (Active, Triggered, Dismissed, Disabled, Expired) |
| **Impact Level** | The expected significance of an economic event (High, Medium, Low) |

---

## 5. Prediction Terms

| Term | Definition |
|------|------------|
| **Model** | The AI/ML algorithm that generates predictions |
| **Prophet** | The specific forecasting model used (developed by Meta) |
| **Feature** | An input variable used by the model to generate predictions |
| **Accuracy** | A measure of how close predictions are to actual prices |
| **RMSE (Root Mean Square Error)** | A metric that measures the average magnitude of prediction errors |
| **MAE (Mean Absolute Error)** | A metric that measures the average absolute difference between predictions and actuals |
| **MAPE (Mean Absolute Percentage Error)** | A metric that measures the average percentage difference between predictions and actuals |
| **Trend** | The general direction of BTC's price (Up, Down, Neutral) |
| **Bullish** | A market condition where prices are expected to rise |
| **Bearish** | A market condition where prices are expected to fall |

---

## 6. Recommendation Terms

| Term | Definition |
|------|------------|
| **Recommendation** | A suggested trading action (BUY, SELL, or HOLD) |
| **Entry Price** | The suggested price at which to enter a trade |
| **Stop-Loss** | The suggested price at which to exit a trade to limit losses |
| **Take-Profit** | The suggested price at which to exit a trade to secure profits |
| **Risk Level** | The degree of risk associated with a recommendation (Low, Medium, High) |
| **Risk-Reward Ratio** | The ratio of potential profit to potential loss |

---

## 7. Correlation Terms

| Term | Definition |
|------|------------|
| **Correlation** | A statistical measure of how BTC moves in relation to a macro indicator |
| **Correlation Coefficient** | A value between -1 and 1 that measures the strength and direction of a relationship |
| **Positive Correlation** | BTC moves in the same direction as the macro indicator |
| **Negative Correlation** | BTC moves in the opposite direction to the macro indicator |
| **Rolling Correlation** | Correlation calculated over a moving window (30d, 90d, 1y) |
| **Statistical Significance** | A measure of confidence that the correlation is not random (p-value < 0.05) |

---

## 8. Regime Terms

| Term | Definition |
|------|------------|
| **Regime** | A distinct macroeconomic environment characterized by specific economic conditions |
| **Regime Type** | A category of economic environment (High Inflation, Low Inflation, Rising Rates, Falling Rates, Recession, Growth) |
| **Regime Detection** | The process of identifying the current macro regime based on economic indicators |
| **Similar Periods** | Historical periods with economic conditions similar to the current regime |
| **Performance Metrics** | BTC performance indicators calculated for each regime (average return, max drawdown, volatility, Sharpe ratio) |

---

## 9. Event Terms

| Term | Definition |
|------|------------|
| **Economic Event** | A scheduled announcement that can impact financial markets (Fed meeting, CPI release, etc.) |
| **Event Impact** | The expected effect of an event on BTC price (High, Medium, Low) |
| **Event Calendar** | A schedule of upcoming economic events |
| **Event History** | A record of past economic events and their impact on BTC |

---

## 10. User Terms

| Term | Definition |
|------|------------|
| **User** | Any person interacting with the platform |
| **Platform User** | A general user of the platform (not trader or analyst specifically) |
| **BTC Trader** | A user who trades BTC using the platform's predictions and alerts |
| **Investment Analyst** | A user who researches BTC and macro data for investment recommendations |
| **Guest** | An unauthenticated user with limited access |
| **Registered User** | An authenticated user with full access to features |
| **Admin** | A user with administrative privileges |
